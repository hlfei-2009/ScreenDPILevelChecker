# ScreenDPILevelChecker
一款由我用 MT管理器 自行开发的 屏幕 DPI 分级检测器，包名为 com.hlfei.android.screen_dpi_level_checker。此应用可以检测出您设备屏幕的当前 DPI 分级，无需任何权限。以 AlertDialog 形式显示界面及检测结果，主题为 DeviceDefault 并适配深色主题，深色和浅色主题可随系统变化而变化。最低支持 Android 5。已引入 英语、阿拉伯语、法语、日语、韩语、俄语、简体中文 和 繁体中文 的语言支持。
